업데이트를 설치하기 전에 변경 내용을 바로 확인할 수 있도록 개선했습니다.

## 추가

- 앱 상단 업데이트 안내에 **Release notes** 링크를 추가했습니다. GitHub 릴리스 노트를 외부 브라우저 새 창에서 열며, 업데이트 설치 중이거나 이미 최신 버전인 경우에도 이용할 수 있습니다.

## 변경

- 앞으로 각 릴리스에 추가·변경·수정사항 요약을 GitHub 자동 변경 기록과 함께 게시합니다. 버전별 요약 파일이 없거나 비어 있으면 게시를 중단합니다.
- 에이전트가 완료된 작업을 `main`에 푸시할 때 버전 업데이트, 검증, Universal DMG 릴리스까지 수행하도록 저장소 지침을 명시했습니다.

## 개선

- 릴리스 검증 중 간헐적으로 실패하던 에디터 모드 전환 커서 테스트의 프레임 실행을 안정화했습니다.
