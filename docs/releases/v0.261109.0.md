## 변경

- WYSIWYG의 Mermaid 다이어그램을 [Pele](https://pele.run) 렌더러로 교체했습니다. 다이어그램이 앱의 라이트·다크 테마 색상과 글꼴을 그대로 따르고, 편집 영역 너비에 맞춰 레이아웃이 바뀌며, 영역보다 큰 다이어그램에는 확대·축소 버튼이 표시됩니다.
- 다이어그램 소스를 고치는 동안 결과가 즉시 다시 그려집니다. 문법이 잘못되면 다이어그램 영역 안에 오류가 표시됩니다.
- Mermaid.js 의존성을 제거해 패키지 크기와 초기 로딩 부담을 줄였습니다. Pele는 Mermaid 코드 블록이 있을 때만 불러옵니다.
