## 추가

- **Prompt selected text**에 **Make list** 모드를 추가했습니다.
- 저장하지 않은 Untitled 탭 하나만 남은 창에서 Cmd+W를 누르면 Zed처럼 창이 닫히고 Markdowner는 계속 실행됩니다. 내용이 있으면 먼저 저장 여부를 묻습니다. 창이 닫힌 상태에서 New·Open 같은 메뉴 명령을 실행하거나 Dock 아이콘을 누르면 창이 다시 열립니다.

## 변경

- **Prompt selected text**의 모드와 모델을 검색 가능한 콤보박스에서 고릅니다. 선택된 모드는 체크 표시와 이름·설명으로 분명하게 보이며, 모델은 이름이나 ID로 검색할 수 있습니다.
- "리스트로 만들어주세요", "표로 정리해주세요", "핵심어를 굵게" 같은 서식 요청은 이제 실제 Markdown(리스트, 체크리스트, 표, 제목, 강조)으로 결과를 만듭니다. Custom instruction, Rewrite, Expand, Make list, Make table 모드가 이 방식을 쓰고, Improve와 Shorten은 기존 서식을 그대로 둔 채 문장만 다듬습니다. 리스트 항목이나 제목 전체를 선택하면 `- `, `## ` 같은 기호까지 함께 바뀌므로 글머리표 리스트를 번호 리스트로 바꾸는 요청도 처리됩니다.
- WYSIWYG에서 링크를 클릭하면 링크 카드만 뜨고 인라인 서식 툴바는 함께 뜨지 않습니다. 링크 카드는 서식 툴바와 같은 모양으로, 위쪽 입력칸에 링크 주소가 보이고 아래에 **Open**, **Copy**, **Remove** 버튼이 있습니다. 입력칸을 클릭하거나 ↑ 키를 누르면 주소 전체가 선택되어 바로 편집할 수 있고, Enter나 **Save**를 누르면 주소가 바뀌고 카드가 닫힙니다.

## 수정

- WYSIWYG 모드에서 AI 결과가 `**굵게**`나 `- 항목`처럼 Markdown 기호가 그대로 보이는 글자로 들어가던 문제를 수정했습니다. 이제 결과가 실제 굵은 글씨, 리스트, 표로 반영되며, 한 번의 실행 취소로 되돌릴 수 있습니다.
