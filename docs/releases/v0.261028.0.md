## 추가

- 파일 메뉴와 명령 팔레트에 **Reload from Disk**를 추가했습니다. 다른 에이전트나 도구가 파일을 바꿨을 때 언제든 디스크 내용으로 다시 불러올 수 있습니다. 저장하지 않은 편집이 있으면 버릴지 먼저 확인합니다.

## 변경

- 외부 변경 알림의 **Reload from disk**는 이제 로컬 편집을 덮어쓰고 디스크 내용을 불러옵니다. 편집 내용이 앱 내부 버퍼와 어긋나 있어도 새로고침이 거절되지 않으며, 다른 문서에는 적용되지 않습니다. 새로고침이 진행되는 동안 입력한 내용은 계속 보존합니다.
- **Keep local**을 누른 뒤에는 디스크 내용이 다시 바뀌기 전까지 같은 충돌 알림이 1초 만에 다시 뜨지 않습니다.

## 수정

- Finder에서 파일을 열거나 `mdner --wait`(Claude Code·Codex의 Ctrl+G 편집)로 파일을 열면서 앱이 시작될 때, 요청한 파일 대신 이전에 보던 문서가 열리거나 요청이 사라지던 문제를 수정했습니다. 외부에서 요청한 파일은 이전 탭 복원이 끝난 뒤 항상 활성 탭으로 열리고, 이전 탭도 함께 유지됩니다. 이미 실행 중인 앱으로 여는 경우에도 같은 경로로 처리합니다.
