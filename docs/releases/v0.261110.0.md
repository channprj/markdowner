## 수정

- WYSIWYG에서 텍스트를 드래그해 링크를 걸 때 URL 입력창에 즉시 포커스가 들어갑니다. 링크 폼을 연 직후 입력한 주소가 본문을 덮어쓰던 문제를 고쳤습니다.
- 링크를 적용하거나 Escape로 닫은 뒤에도 에디터 포커스가 유지되어 바로 이어서 입력할 수 있습니다. 링크 카드에는 링크할 텍스트가 미리 표시됩니다.
- 드래그한 선택 범위를 툴바와 메뉴가 직접 전달하므로, 링크 폼이 열리는 동안 선택이 바뀌어도 원래 텍스트에 정확히 적용됩니다.

## 추가

- 선택 영역에서 `Cmd+/`를 누르고 **Link**를 골라 하이퍼링크를 걸 수 있습니다. Turn-into 메뉴의 Link는 블록 형식을 바꾸지 않고 선택한 텍스트에만 링크를 적용합니다.
