## 수정

- 앱 시작 시 이전 탭을 복원하는 동안 새 파일을 열거나 편집하면, 현재 파일과 입력한 내용이 이전 상태로 돌아가던 문제를 수정했습니다. 이전 탭과 복구할 초안은 현재 작업을 유지한 채 복원합니다.
- 디스크 새로고침 중 편집하거나 자동 갱신과 수동 새로고침이 겹치면 이후 새로고침이 계속 실패하던 문제를 수정했습니다. 새로고침 중 입력한 내용은 보존하며, 다시 요청하면 최신 디스크 내용을 불러올 수 있습니다.
- 여러 파일을 한 번에 열 때 이미 열린 파일이나 중복된 경로가 포함되면, 선택된 탭과 표시되는 파일 내용이 달라지던 문제를 수정했습니다.
- 자동 새로고침과 저장이 겹칠 때 저장이 거절되거나, 느린 저장 중 추가한 내용의 자동 저장이 멈추던 문제를 수정했습니다.
- 저장 창이나 닫기 확인 창을 기다리는 동안 다른 파일을 열면 이전 요청이 새 파일을 저장하거나 닫지 않도록 했습니다. 저장 후 닫기 중 입력한 내용은 탭을 유지해 보존합니다.
- 심볼릭 링크로 연 파일을 저장하면 링크가 일반 파일로 바뀌고 원본 파일은 갱신되지 않던 문제를 수정했습니다. 링크를 유지하면서 실제 대상 파일을 저장합니다.
