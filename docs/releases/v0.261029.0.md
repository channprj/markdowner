## 추가

- WYSIWYG에서 `Cmd+Shift+K`를 누르면 Zed의 줄 삭제처럼 커서나 선택이 걸친 블록을 지웁니다. 문단과 제목은 블록 전체를, 리스트 항목은 하위 항목까지 함께 지웁니다. 코드 블록 안에서는 해당 코드 줄만, 표 안에서는 해당 행만 지우고, 머리글 행을 지우면 다음 행이 머리글이 됩니다. 한 번의 실행 취소로 되돌릴 수 있습니다.

## 변경

- 인라인 AI 프롬프트(**Run AI on Selection**)의 기본 단축키가 `Cmd+Shift+K`에서 `Cmd+Shift+I`로 바뀌었습니다. Source와 WYSIWYG 모두 같은 키로 열립니다. `Cmd+Shift+K`는 Zed처럼 줄 삭제에 씁니다.
- **Document Stats**의 기본 단축키가 `Cmd+Shift+I`에서 `Cmd+Shift+C`로 바뀌었습니다. 명령 팔레트에도 바뀐 키가 표시됩니다.
- 단축키를 직접 바꿔 둔 설정은 그대로 유지되고, 새 기본 단축키와 겹치면 직접 지정한 쪽이 우선합니다. 다만 AI 프롬프트를 `Cmd+Shift+K`로 지정해 두었다면, 이 키가 이제 줄 삭제 전용이므로 기본값인 `Cmd+Shift+I`로 동작합니다.

## 수정

- Source 모드에서 텍스트를 선택하고 `Cmd+Shift+K`로 AI 프롬프트를 열려고 하면, 프롬프트는 열리지 않고 선택한 줄이 지워지던 문제를 수정했습니다.
