## 추가

- **Settings → Developer → Developer Mode**를 켜면 웹 인스펙터(DevTools)가 열리고 React Grab이 활성화됩니다. 인스펙터를 닫은 뒤에는 같은 섹션의 **Open DevTools**로 다시 열 수 있습니다.
- 개발자 모드에서 `Opt+C`를 누르면 React Grab 선택 모드가 즉시 켜집니다. UI 요소를 클릭해 React 컴포넌트와 소스 위치를 복사할 수 있으며, WYSIWYG 에디터에 포커스가 있어도 동작합니다.

## 참고

- 개발자 모드는 기본적으로 꺼져 있고 앱 설정과 함께 저장됩니다. 모드를 끄면 React Grab 오버레이와 DevTools가 함께 닫힙니다.
- 웹 인스펙터를 배포 빌드에서도 열 수 있도록 Tauri `devtools` 기능을 켰습니다. 개발자 모드를 켜지 않은 일반 사용 환경에서는 DevTools와 React Grab이 로드되지 않습니다.
