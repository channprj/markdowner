## 수정

- **Prompt selected text**(Cmd+Shift+K)를 열 때 "Minified React error #185" 오류 화면으로 바뀌며 앱을 계속 쓸 수 없던 문제를 수정했습니다. 편집 직후에 프롬프트를 열거나 모드·모델 목록을 펼쳐 둔 상태에서도 더 이상 멈추지 않습니다. 소스 편집기도 앱이 다시 그려질 때마다 설정을 다시 적용하지 않아 입력 중 불필요한 다시 그리기가 줄었습니다.
- 선택한 문단을 리스트나 표로 바꿀 때 숫자만 있는 문단(예: `123123`)이 리스트에 들어가지 않고 따로 남던 문제를 수정했습니다. 이제 숫자도 다른 문장처럼 리스트 항목이나 표 칸으로 옮겨집니다. 숫자가 바뀌거나 빠지거나 순서가 뒤바뀐 결과는 이전처럼 적용하지 않고 검토 화면으로 보냅니다.
- "1) 열기 2) 닫기 3) 저장"처럼 문장 안에 매긴 번호를 리스트로 바꾸는 요청이 검증에서 거부되던 문제를 수정했습니다. 이런 번호는 번호 리스트의 번호가 되거나, `1)` 형식이면 글머리표 리스트로 바뀔 수 있습니다.
- 수정하지 않은 다른 탭으로 전환할 때 잠깐 동안 새 탭이 수정됨 표시와 함께 이전 문서 내용 위에 선택되어 보이던 문제를 수정했습니다. 탭과 문서 내용이 이제 함께 바뀝니다.
